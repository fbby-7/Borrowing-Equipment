FULLBRIGHT COLLEGE - UPDATED WEBSITE SETUP

1. Supabase
   - Your existing database is kept.
   - Run supabase_upgrade.sql ONCE in Supabase SQL Editor.
   - Do NOT rerun the original clean-install supabase_schema.sql if your database already contains data.

2. Supabase Auth
   - Authentication -> Sign In / Providers -> Email
   - Allow new users to sign up: ON
   - Confirm Email: OFF if you want students to sign in immediately without email confirmation.
   - Supabase documents that when Confirm Email is disabled, signUp returns a user and session.

3. Website connection
   - Open assets/app.js
   - Replace YOUR_SUPABASE_PROJECT_URL with your project URL.
   - Replace YOUR_SUPABASE_PUBLISHABLE_KEY with your Supabase publishable key.
   - Never put a Supabase secret/service-role key in this website.

4. Netlify
   - Zip the contents of this folder.
   - Upload the ZIP/folder to your Netlify site.
   - If your old deployment is cached, trigger a new deploy and hard-refresh the browser.

5. First administrator
   - Create your account through the website.
   - In Supabase Table Editor -> users, set that account's role_id to 1 (Administrator).
   - After that, the User Management page can change roles, status, course/year and department.
